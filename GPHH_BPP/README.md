## Compile, Train and Test
I actually like to put these cache files into the *out*..

```bash
javac -d out *.java
```

```bash
java -cp out GPHH20617232 --train [--seed RANDOM_NUM]
```

```bash
java -cp out GPHH20617232 -s INSTANCE_FILE -o SOLUTION_FILE [-t MAX_TIME]
```
